# Next.js on Vercel, one page for v1

The site is a single page built with Next.js (App Router), TypeScript and Tailwind, deployed on Vercel Hobby. Next.js is on my learning list, it suits the later Claude API "Ask about me" chat, and the site doubles as a Next.js sample. Vercel builds every push and posts preview links on pull requests. Astro and Vite + React were simpler for a static page but give up that later path. GitHub Pages has no preview deployments.

v1 launches on the free `*.vercel.app` address. A custom domain (about $10–15 a year) waits until there is a shipped project to point at. Project detail pages, a blog, a theme toggle and the chat are deferred, so v1 stays small enough to hit the targets in `docs/spec.md`.
