# portfolio

My portfolio site and résumé: Next.js, TypeScript and Tailwind on Vercel. The résumé PDF is generated from the same typed content as the site.

Work in progress. The plan is in [`docs/spec.md`](docs/spec.md), the decisions are in [`docs/adr/`](docs/adr/), and the work is tracked in [Issues](https://github.com/AneshSM/portfolio/issues). It's built with Claude Code, test-first, one reviewed PR per ticket.
